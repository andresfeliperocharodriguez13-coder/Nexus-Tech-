# 📰 Nexus Tech
## 📖 Descripción

**Nexus Tech** es una página web inspirada en una revista de tecnología moderna. Su objetivo es presentar noticias, tendencias e información del mundo tecnológico mediante una interfaz limpia, atractiva y fácil de navegar.

El proyecto fue desarrollado utilizando tecnologías web básicas, enfocándose en un diseño responsive y una experiencia de usuario agradable.

## 💻 Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/andresfeliperocharodriguez13-coder/Nexus-Tech-.git
```

2. Entra a la carpeta del proyecto:

```bash
cd Nexus-Tech-
```

3. Abre el archivo **index.html** en tu navegador.
